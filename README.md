# Видео в голосовом чате Telegram (юзербот на Railway)

## Установка с нуля
1. **Аккаунт.** Лучше отдельный (не основной): юзерботы формально нарушают правила Telegram, риск лимитов/бана есть.
   Аккаунт должен быть участником нужной группы.
2. **API_ID / API_HASH.** https://my.telegram.org → API development tools → создать приложение.
3. **SESSION_STRING.** На своём ПК: `pip install pyrogram tgcrypto`, затем `python gen_session.py`.
   Введи API_ID, API_HASH, номер телефона и код. Скопируй выданную строку.
4. **CHAT.** ID группы вида `-1001234567890` (узнать можно у @getidsbot, переслав ему сообщение из группы).
5. **ADMINS.** Твои user ID через запятую (у @userinfobot).
6. **GitHub.** Залей эти файлы в приватный репозиторий (без секретов!).
7. **Railway.** New Project → Deploy from GitHub repo. Он сам найдёт Dockerfile.
   Вкладка Variables: `API_ID`, `API_HASH`, `SESSION_STRING`, `CHAT`, `ADMINS`
   (необязательно `VIDEO_QUALITY` = 480 / 720 / 1080).
8. В логах должно появиться `✅ Вижу чат`.

## Использование
Запусти голосовой чат в группе, ответь на видео командой:
- `/play` — запуск, `/stop` — стоп
- `/pause`, `/resume`
- `/seek +30`, `/seek -10`, `/seek 120`
- `/ping` — проверка, что бот жив

## Звук и синхронизация
- Бот не применяет никакого шумоподавления: звук идёт как есть, 48 кГц стерео.
- Рассинхрон почти всегда из-за нехватки CPU на сервере. Держи `VIDEO_QUALITY=720`;
  1080 включай только если сервер тянет.
- Лучше исходные видео в H.264/AAC: ffmpeg перекодирует их легче.

## Безопасность
SESSION_STRING = полный доступ к аккаунту. Храни только в Variables Railway.
Если строка где-то засветилась: Telegram → Настройки → Устройства → завершить сеанс.
